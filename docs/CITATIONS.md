# Citations

rlm0 is a clean-room implementation, but its methods have direct research
sources. Cite the original RLM paper when you use the core runtime. If an
optional module matters to your work, cite its source as well.

The repository itself has machine-readable citation metadata in
[`CITATION.cff`](../CITATION.cff).
